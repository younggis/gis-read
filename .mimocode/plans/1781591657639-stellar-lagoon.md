# 3D Tiles Generation Implementation Plan

## Overview

Add `3dtiles` CLI command to generate OGC 3D Tiles (B3DM) from polygon data (Shapefile, GeoJSON, etc.) with height extrusion. Reference: `3dtiles-master/` (fanvanzh/3dtiles, Rust+C++ hybrid).

## Data Flow

```
Shapefile/GeoJSON → parseFile() → CRS transform → Quadtree partition
    → Per-tile: extrude polygons → merge meshes → build GLB → build B3DM → write content.b3dm
    → Write tileset.json hierarchy
```

## CLI Interface

```
gis 3dtiles <input> -o <dir> [--height <field>] [--default-height <n>] [--from-crs <crs>] [--leaf-size <n>]
```

## Implementation Phases

### Phase 1: Geo Utilities (src/io.ts)
- Extract `wgs84ToECEF` from `quantized-mesh.ts:114`
- Port `calcEnuToEcefMatrix` from `coordinate_transformer.cpp:343`
- Port `latToMeter`/`lonToMeter` from `tileset.cpp:176`

### Phase 2: GLB Builder (src/parsers/glb.ts)
- Manual binary serialization (zero new deps)
- Buffer layout: indices → positions → normals → batchIds (each 4-byte aligned)
- Accessors/BufferViews with min/max
- GLB: header(12B) + JSON chunk + BIN chunk, total 8-byte aligned

### Phase 3: B3DM Writer (src/parsers/b3dm.ts)
- 28-byte header + feature table JSON + batch table JSON + GLB
- All sections 8-byte aligned
- Batch table: per-feature property arrays

### Phase 4: Polygon Extrusion (src/parsers/polygon-extrude.ts)
- Wall generation: quad per edge segment (2 triangles)
- Roof/floor via `earcut` (already installed)
- Coordinate projection: WGS84 → local ENU meters
- Support MultiPolygon and holes

### Phase 5: Tileset Generator (src/parsers/tileset.ts)
- Quadtree spatial partitioning (leaf size ~0.01°)
- Per-tile bounding box (12-float box format)
- Bottom-up hierarchy assembly (max 4 levels)
- ENU→ECEF root transform

### Phase 6: Orchestrator (src/parsers/threed-tiles.ts)
- Pipeline: parse → CRS transform → quadtree → per-tile extrude+GLB+B3DM → tileset.json

### Phase 7: CLI (src/cli.ts)
- `3dtiles` command following existing patterns

## Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| GLB builder | Manual binary | Zero new deps, full control |
| LOD support | Defer | Get basic pipeline working first |
| Mesh simplification | Defer | meshoptimizer WASM adds complexity |
| Draco compression | Defer | draco3d WASM adds complexity |
| Batch table | JSON only (no SQLite) | Simpler, covers most cases |
